# ilogix-lead-runs

Public instructions for AI lead-research runs. No customer data, no emails, no phone numbers.

- `MASTER_SMALL_BUSINESS.md`: rules and checks for small-business runs
- `MASTER_MIDSIZE.md`: rules and checks for mid-size company runs
- `PLAYBOOKS.md`: typical problems per segment
- `SKIP_LIST.txt`: domains and names already handled (do not return)
- `runs/`: one file per run (country, niche, cities)

To start a run, paste into ChatGPT (browsing on):

> Open this run file with browsing and follow it exactly. It tells you which other files to read. https://raw.githubusercontent.com/chandrams512/ilogix-lead-runs/main/runs/<run file name>
